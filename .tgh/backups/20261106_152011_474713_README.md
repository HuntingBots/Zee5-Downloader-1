# TGH Universal OTT Downloader

A modular, production-ready Telegram bot for media metadata analysis and downloading.

## Features

- **Modular Architecture**: Easily add new provider adapters.
- **Media Analysis**: Uses FFprobe to extract resolution, bitrate, codecs, and more.
- **Telegram UI**: Interactive inline buttons for format selection.
- **Database Integration**: MongoDB for user management and download logging.
- **Dockerized**: Ready for deployment via Docker and Docker Compose.

## Technical Stack

- Python 3.11
- Pyrogram (Telegram Bot Framework)
- MongoDB (Database)
- FFmpeg & FFprobe (Media Processing)
- Docker & Podman (Containerization)

## Setup & Deployment

### 1. Prerequisites

- Docker and Docker Compose installed.
- Telegram API ID and Hash (from [my.telegram.org](https://my.telegram.org)).
- Bot Token (from [@BotFather](https://t.me/BotFather)).

### 2. Configuration

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

### 3. Run with Docker

```bash
docker-compose up -d --build
```

### 4. Manual Installation (VPS)

```bash
sudo apt update && sudo apt install ffmpeg python3-pip -y
pip install -r requirements.txt
python3 bot.py
```

## Usage

Send `/rip <url>` to the bot. The bot will analyze the link and present available formats.

## Security & Compliance

This bot is designed for **authorized media analysis and downloading only**.
- It does **not** bypass DRM (Widevine, etc.).
- It does **not** extract protected keys.
- It does **not** circumvent subscription restrictions.
- Users are responsible for ensuring they have the right to download the content.
